# Calculator

A desktop calculator application developed in **C++** using **Qt**.

The project provides a graphical interface for performing arithmetic calculations and includes expression processing using Reverse Polish Notation.

## Features

- Graphical user interface
- Basic arithmetic operations
- Expression input
- Expression evaluation
- RPN-based expression processing

## Technologies

- **C++**
- **Qt**
- **Qt Creator**

## Project Structure

The project contains separate components for:

- Calculator logic
- RPN expression processing
- User interface

## How to Run

1. Open the `.pro` project file in **Qt Creator**.
2. Configure the Qt kit.
3. Build the project.
4. Run the application.

## Purpose

This project was created to practice:

- C++ programming
- Qt GUI development
- Working with classes
- Expression parsing
- Reverse Polish Notation (RPN)
