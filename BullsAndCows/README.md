# Bulls and Cows

A classic number-guessing game developed in **C++** using **Qt**.

The player has to guess a hidden number. After each attempt, the game provides feedback by counting **bulls** and **cows**.

## Features

- Hidden number generation
- User input through a graphical interface
- Automatic calculation of bulls and cows
- Feedback after each attempt
- Graphical user interface

## Technologies

- **C++**
- **Qt**
- **Qt Creator**

## How to Run

1. Open the project in **Qt Creator**.
2. Open the `.pro` project file.
3. Configure the Qt kit.
4. Build the project.
5. Run the application.

## Purpose

This project was created to practice:

- C++ programming
- Object-oriented programming
- Working with Qt
- Event-driven GUI development
- Basic game logic
