# Tic-Tac-Toe

A graphical Tic-Tac-Toe game developed in **C++** using **Qt**.

The game supports both playing against another person and playing against the computer.

## Features

- Graphical user interface
- Two-player game mode
- Player vs. computer mode
- Automatic win detection
- Automatic draw detection
- Game board interaction
- Restarting the game

## Game Modes

### Player vs. Player

Two players can play against each other on the same computer.

### Player vs. Computer

The player competes against the computer.

## Technologies

- **C++**
- **Qt**
- **Qt Creator**

## How to Run

1. Open the `.pro` project file in **Qt Creator**.
2. Configure the Qt kit.
3. Build the project.
4. Run the application.

## Purpose

This project was created to practice:

- C++ programming
- Qt GUI development
- Event handling
- Game logic
- Working with classes and objects
- Implementing win and draw conditions
